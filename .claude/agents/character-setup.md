# キャラクターセットアップ

## 実行フロー

1. PSD構造解析
2. パーツ抽出（`extract-psd-parts.py`、**topil()使用**）
3. 英語名変換（`rename-parts-to-english.py`）
4. 日本語パーツ削除
5. コンポーネント確認

## 生成ファイル

```
public/parts/<character>_en/
├── body.png
├── head_front/
│   ├── eye/
│   ├── mouth/
│   └── ...
```

## 重要な口マッピング

| 日本語 | 英語 | 説明 |
|--------|------|------|
| むふ | closed | 閉じた口 |
| ほう | u | すぼめた口 |
| ほあ | a | 開いた口 |

## エラー対応

| 問題 | 原因 | 対処 |
|------|------|------|
| 空画像 | composite()使用 | topil()に変更 |
| 404エラー | 日本語ファイル名 | 英語に変換 |
