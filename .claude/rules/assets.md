# 素材ルール

BGM・効果音・立ち絵・背景画像・参考画像・音声のライセンス判断と置き場所のルール。
**このルールは厳守すること。** 判断に迷ったら使わずに確認する。

## 大原則

1. **公開リポジトリへのコミットは「再配布」にあたる。** 商用利用OKでも再配布NGの素材は
   コミットしてはいけない
2. **一覧に載っているソースだけしか使えないわけではない。**
   下記の条件をすべて満たせば、どのソースを使ってもよい
3. **ただし条件の確認手順は省略しない。** 「たぶん大丈夫」で進めない
4. **規約は変わる。** 一覧の情報は調査時点のもの。使うたびに配布元の規約を見る

## 判定条件

素材を使う前に、この5つを配布元の規約で確認する。

| # | 条件 | なぜ必要か |
|---|------|-----------|
| 1 | **商用利用が可能か** | 動画が収益化される可能性がある |
| 2 | **再配布が可能か** | リポジトリにコミットする＝再配布 |
| 3 | **改変が可能か** | 切り出し・リサイズ・音量調整・パーツ化をする |
| 4 | **クレジット表記の条件を満たせるか** | 満たせないなら使わない |
| 5 | **用途の制限に抵触しないか** | 素材集としての配布禁止・AI学習禁止など |

条件3は必要なときだけ見ればよい（BGMをそのまま流すだけなら不要）。

## 置き場所の判定

```
条件1（商用利用）を満たさない
  └→ 使わない

条件1を満たし、条件2（再配布）を満たさない
  └→ public/audio/bgm/local/ など local/ に置く（.gitignoreで除外済み）
     別環境では手動でダウンロードして配置する

条件1〜5をすべて満たす
  └→ public/ にコミットし、同じディレクトリのCREDITS.mdに追記する
```

| 置き場所 | git管理 | 用途 |
|----------|---------|------|
| `public/audio/bgm/` `public/audio/se/` `public/images/` `public/parts/<name>/` | する | 再配布可の素材 |
| `public/audio/bgm/local/` `public/audio/se/local/` | **しない** | 再配布不可の素材 |

`generate-from-scenes.sh` がBGMと効果音のファイル実在と置き場所をチェックし、
コミット対象の場所にある場合は注意を表示する。

## 検証済みのソース（候補）

**この一覧は候補であって制限ではない。** 条件を満たす他のソースも使ってよい。
リンク先の規約が正であり、下記は調査時点の要約。

### 最も安全（CC0・パブリックドメイン）

クレジット不要、再配布・改変とも自由。迷ったらここから選ぶ。

### 独自ライセンス（再配布可・制限あり）

プロジェクトの一部として使うぶんには問題ないが、**素材集としての再配布は不可**。

| ソース | 種類 | 要点 |
|--------|------|------|
| [Unsplash](https://unsplash.com/license) | 写真 | 商用可・表記不要・改変可。**無改変での販売禁止**、競合サービスの構築禁止 |
| [Pexels](https://www.pexels.com/license/) | 写真・動画 | 商用可・表記不要・改変可。**他のストックサイトへの再配布禁止**、無改変の物理販売禁止 |
| [Pixabay](https://pixabay.com/service/license-summary/) | 写真・イラスト・音源 | 商用可・表記不要。**単体（Standalone）での配布・販売禁止** |
| [unDraw](https://undraw.co/license) | イラスト | 商用可・表記不要・改変可。**素材集としての配布禁止・AI学習への利用禁止** |

### 音声合成（キャラクターごとに規約が違う）

**VOICEVOXは話者ごとに規約が異なる。** 話者IDで決め打ちしない。
エンジンが公式の規約文を同梱しているので、そこを一次情報として確認する。

```bash
# 話者IDから話者を特定する
curl -s http://127.0.0.1:50021/speakers | jq -r '.[] | . as $s | .styles[] | "\(.id) \($s.name)/\(.name) \($s.speaker_uuid)"'

# その話者の公式規約を読む
curl -s "http://127.0.0.1:50021/speaker_info?speaker_uuid=<UUID>" | jq -r .policy
```

確認するのは次の3点。

- クレジットの**正確な表記**（`VOICEVOX:キャラクター名` の形式。話者IDを書くのは不可）
- 商用利用の可否
- **法人が関わる場合の追加条件**（話者によっては事前確認が必要）

採用中の話者:

| 話者ID | キャラクター | 要点 |
|--------|-------------|------|
| 3 | ずんだもん | `VOICEVOX:ずんだもん`。[規約](https://zunko.jp/con_ongen_kiyaku.html) |
| 11 | 玄野武宏 | `VOICEVOX:玄野武宏`。法人利用の追加条件なし |

参考: 話者13（青山龍星）は「企業が携わる形で利用する場合は事前確認が必要」。
このような追加条件があるものは、条件を満たせないなら選ばない。

## 再配布不可の代表例（local/ に置く）

日本語のフリー素材サイトは「商用利用OK」でも**素材ファイルそのものの再配布は禁止**が多い。
下記は使ってよいが、**コミットしてはいけない**。

- 効果音ラボ
- 魔王魂
- DOVA-SYNDROME
- いらすとや
- 購入した音源・イラスト

これらを使う場合は `local/` に置き、シーンYAMLからは
`audio/bgm/local/xxx.mp3` のように参照する。README等に入手手順を書いておく。

## 新しいソースを使う手順（厳守）

1. **配布元の規約ページを開いて読む。** まとめ記事や記憶で判断しない
2. 上の5条件を1つずつ確認する。**1つでも不明なら使わない**
3. 置き場所を判定表どおりに決める
4. コミットする場合は、そのディレクトリの `CREDITS.md` に次を書く
   - 素材名・作者・配布元URL・ライセンス名とURL・入手日
   - CC BY等で表記義務がある場合は、**動画に出す文言**も明記する
5. 表記義務がある場合は、動画のクレジットに反映する
   - BGM → シーンYAMLの `bgm.credit`
   - キャラクター（声・立ち絵）→ `src/characters/<name>/character.json` の `credits`
   - 効果音・画像 → 表記が必要なら `bgm.credit` に併記するか、専用の表記を検討する

## クレジットの書き方

動画末尾のクレジットは自動で表示される。

| 対象 | 書く場所 |
|------|---------|
| 声・立ち絵 | `src/characters/<name>/character.json` の `credits`（**出てきた全キャラクターぶんが自動で並ぶ**） |
| BGM | シーンYAMLの `bgm.credit` |

CC BYは表記が**義務**なので、省略するとライセンス違反になる。
「作者名 / 作品名 / ライセンス名」が分かる形で書く。

```yaml
bgm:
  src: "audio/bgm/carefree-kevin-macleod.mp3"
  credit: "BGM: Carefree - Kevin MacLeod (incompetech.com) / CC BY 4.0"
```

## やってはいけないこと

- 規約を確認せずにコミットする
- 「商用利用OK」だけを見て再配布可否を確認しない
- まとめ記事の記載を一次情報として扱う
- クレジット表記の義務がある素材を、表記せずに使う
- パブリックドメインの**楽曲**と、その**録音**を混同する
  （楽曲がPDでも演奏・録音には別途権利があることが多い）
- 生成AIの出力を、学習元の権利が不明なまま素材として使う
- `local/` に置くべき素材を `public/` 直下に置く

## グレーな判断をしている箇所

条件が明文化されておらず、**判断でコミットしている**素材がある。
扱いを変えるときは必ず `public/parts/zundamon_en/CREDITS.md` を読むこと。

### ずんだもん立ち絵（`public/parts/zundamon_en/`）

坂本アヒル氏の立ち絵は「公式の規約の範囲なら何に使ってもだいじょうぶ」とされ、
公式規約に委ねられている。その公式規約では、

- 3Dモデルの再配布は**明示的に許可**
- イラストは**販売の禁止**のみ記載
- **イラストの無償再配布は許可も禁止も明記されていない**

このリポジトリは「OSS・無償・立ち絵が主体ではない・販売していない」ことから
**禁止に該当しないと判断して**コミットしている。明示的な許可ではない。

**新しい素材にこの判断を横展開しないこと。** 5条件のうち「再配布可否が不明」は
本来 `local/` 行きであり、これは既存の経緯を踏まえた例外にあたる。

### 商用利用の制約（ずんだもん）

フォークや商用利用では条件が変わる。

| 立場 | 扱い |
|------|------|
| 東北6県に本社を置く企業・公共団体 | 商用利用可 |
| **それ以外の企業・法人** | **別途ライセンス契約が必要** |
| 個人のYouTube広告収入・投げ銭 | 例外として可 |
| クリエイターの二次創作 | 原則非営利 |

法人での商用利用が絡む場合は、立ち絵の制約が無い `presenter`
（Avataaars / MIT ＋ VOICEVOX玄野武宏）を勧める。
