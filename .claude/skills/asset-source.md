# 素材の取得元を選ぶ

**判断基準は `.claude/rules/assets.md` にある。必ずそれに従うこと。**
このスキルは、候補を出して確認を進めるための手順書。

## 進め方

### 1. 何が必要かを確認する

| 種類 | 置き場所 | クレジットの反映先 |
|------|---------|------------------|
| BGM | `public/audio/bgm/` | シーンYAMLの `bgm.credit` |
| 効果音 | `public/audio/se/` | 必要なら `bgm.credit` に併記 |
| 立ち絵・キャラクター | `public/parts/<name>/` | `character.json` の `credits` |
| 背景画像・参考画像 | `public/images/` | 必要なら `bgm.credit` に併記 |
| 音声（話者） | 生成物のみ | `character.json` の `credits` |

### 2. 候補を提案する

まず**すでに採用済みのソース**を確認する。同じソースで足りるなら追加調査は不要。

| 用途 | 採用中 | ライセンス |
|------|--------|-----------|
| 効果音 | Kenney | CC0 |
| BGM | Incompetech (Kevin MacLeod) | CC BY 4.0 |
| 立ち絵 | Avataaars | MIT |
| 声 | VOICEVOX（ずんだもん / 玄野武宏） | 話者ごとの規約 |

足りない場合は `.claude/rules/assets.md` の一覧から、
**安全な順**（CC0 → CC BY/MIT → 独自ライセンス）に候補を出す。

一覧に無いソースをユーザーが希望する場合も、**条件を満たせば使ってよい**。
その場合は次のステップを必ず実施する。

### 3. ライセンスを確認する

**配布元の規約ページを開いて読む。まとめ記事や記憶で判断しない。**

`.claude/rules/assets.md` の5条件を1つずつ潰す。

1. 商用利用が可能か
2. 再配布が可能か（コミットするなら必須）
3. 改変が可能か（切り出し・音量調整などをするなら）
4. クレジット表記の条件を満たせるか
5. 用途の制限に抵触しないか（素材集としての配布禁止・AI学習禁止など）

**1つでも不明なら使わない。** 代替を提案する。

VOICEVOXの話者はエンジンが公式規約を同梱しているので、そこを見る。

```bash
curl -s http://127.0.0.1:50021/speakers | jq -r '.[] | . as $s | .styles[] | "\(.id) \($s.name)/\(.name) \($s.speaker_uuid)"'
curl -s "http://127.0.0.1:50021/speaker_info?speaker_uuid=<UUID>" | jq -r .policy
```

### 4. 置き場所を決める

```
商用利用NG            → 使わない
商用OK・再配布NG      → local/ に置く（.gitignore済み。コミットしない）
すべて満たす          → public/ にコミット
```

### 5. CREDITS.md に記録する

コミットする場合のみ。同じディレクトリの `CREDITS.md` に追記する。

```markdown
## <ファイル名>

- 素材名:
- 作者:
- 配布元: <URL>
- ライセンス: <名称> (<URL>)
- 入手日:
- 動画に出す表記: <CC BY等で義務がある場合の文言>
```

### 6. クレジットを動画に反映する

表記義務がある場合のみ。反映を忘れるとライセンス違反になる。

```yaml
# BGM
bgm:
  src: "audio/bgm/xxx.mp3"
  credit: "BGM: 曲名 - 作者 (配布元) / CC BY 4.0"
```

```json
// キャラクター（声・立ち絵）
"credits": ["VOICEVOX:玄野武宏", "立ち絵: Avataaars by Pablo Stanley (MIT)"]
```

### 7. 動作確認

```bash
npm run voice -- scenes/<name>.yaml   # 素材の実在と置き場所をチェックする
```

`generate.mjs` がBGM・効果音のファイル実在を確認し、
コミット対象の場所にある場合は注意を表示する。

## ユーザーへの伝え方

候補を出すときは、**ライセンスの種類と制約をセットで**伝える。
「使えます」だけでは判断材料にならない。

```
BGMの候補です。

1. Incompetech（採用中・CC BY 4.0）
   → 表記義務あり。すでにクレジットの仕組みがあるので追加コストなし
2. OtoLogic（CC BY 4.0・日本語サイト）
   → 表記義務あり。和風・環境音が充実
3. DOVA-SYNDROME
   → 商用OKだが再配布NG。local/ に置く運用になり、
     別環境では手動ダウンロードが必要

1か2ならリポジトリにコミットできます。どれにしますか？
```

## よくある間違い

- 「商用利用OK」だけ見て再配布可否を確認しない（日本語のフリー素材サイトは**再配布禁止が多い**）
- パブリックドメインの**楽曲**と、その**録音**を混同する（録音には別途権利があることが多い）
- Freesound や Wikimedia Commons を「サイト全体で1つのライセンス」と思い込む（**ファイルごとに違う**）
- VOICEVOXの話者を話者IDで決め打ちし、キャラごとの規約を見ない
- クレジット表記を `VOICEVOX（話者ID: 3）` のように書く（規約は `VOICEVOX:キャラクター名` を求めている）
