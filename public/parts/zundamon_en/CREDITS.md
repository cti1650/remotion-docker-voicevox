# ずんだもん立ち絵パーツのクレジット

このディレクトリのPNGは、坂本アヒル氏が配布している「ずんだもん立ち絵素材」のPSDから
パーツを抽出し、ファイル名を英語に変換したものです（`scripts/extract-psd-parts.py` と
`scripts/rename-parts-to-english.py`）。一部の口パーツは既存パーツから生成しています
（`scripts/generate-mouth-parts.py`）。

## 出典

| 項目 | 内容 |
|------|------|
| 素材名 | ずんだもん立ち絵素材（v2.3系） |
| 作者 | 坂本アヒル |
| 配布元 | https://seiga.nicovideo.jp/seiga/im10788496 |
| キャラクター | ずんだもん（東北ずん子・ずんだもんプロジェクト） |
| 公式ガイドライン | https://zunko.jp/guideline.html |

動画内のクレジットは `src/characters/zundamon/character.json` の `credits` で
自動表示されます。

```
VOICEVOX:ずんだもん
立ち絵素材: 坂本アヒル
```

## 利用条件

**2つの規約が重なっています。**

### 1. 立ち絵イラスト（坂本アヒル氏）

配布ページの記載は次のとおりで、**独自の制約は課さず公式規約に委ねる**形です。

> 公式の規約の範囲なら何に使ってもだいじょうぶ！

クレジット表記は任意、改変も可。

### 2. 東北ずん子・ずんだもんプロジェクト公式ガイドライン

再配布に関する記載は次の2点です。

| 対象 | 記載 |
|------|------|
| 3Dモデル | 「公式が配信している3Dモデルを改造して**再配布しても大丈夫**です」 |
| イラスト | 「キャラクターのイラスト、３Ｄモデル、音声そのもの、もしくは**素材が主たるものになっているケースでは販売することは禁止**」 |

**イラストの無償再配布については、許可も禁止も明記されていません。**
GitHub等のソースコード配布への同梱についても記載がありません。

## このリポジトリでコミットしている理由

明示的な許可があるわけではなく、**下記の判断に基づいています**。

- このリポジトリはOSSで、**無償**で配布している
- 立ち絵は**主たるものではない**（動画生成テンプレートのデモ用素材）
- 素材そのものを**販売していない**
- 明文の禁止事項（販売・NFT化・公序良俗違反など）には該当しない

つまり「禁止されていないと判断した」のであって、
**「明示的に許可されている」わけではありません。**

## フォークして使う場合の注意

**特に商用利用する場合は、必ず自分で規約を確認してください。**
このリポジトリの判断がそのまま当てはまるとは限りません。

### 商用利用の制約（公式ガイドライン）

| 立場 | 扱い |
|------|------|
| 東北6県に本社を置く企業・公共団体 | 商用利用可 |
| **それ以外の企業・法人** | **別途ライセンス契約が必要** |
| 個人のYouTube広告収入・投げ銭・クリエイター奨励プログラム | 例外として可 |
| クリエイターの二次創作 | 原則非営利（同人即売会等の原価回収は可） |

### 判断に迷う場合

- **法人での利用**を検討している → [キャラクターライセンス窓口](https://zunko.jp/con_shoushi.html) に確認する
- **立ち絵素材の再配布**が要件に含まれる → 坂本アヒル氏と公式の双方に確認する
- 確認が取れない → このディレクトリを配布物から外し、各自がPSDから生成する運用にする
  （`scripts/setup-zundamon.sh` がPSDからの抽出に対応しています）

商用前提で立ち絵の制約を避けたい場合は、**`presenter` キャラクターを使う**選択肢もあります。
Avataaars（MIT）＋ VOICEVOX玄野武宏（法人利用の追加条件なし）の組み合わせです。
