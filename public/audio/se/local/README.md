# 再配布NGの効果音を置く場所

このディレクトリは`.gitignore`で除外している（README.mdだけコミットする）。

効果音ラボ・魔王魂・購入した音源など、**素材ファイルの再配布が禁止されている**
ものはここに置く。日本語のフリー効果音サイトは「商用利用OK」でも再配布は
禁止していることが多いので、迷ったらここに置けば規約違反にはならない。

```yaml
scenes:
  - text: "セリフ"
    se: "audio/se/local/pon.mp3"
```

再配布が許可されている素材（CC0など）は`public/audio/se/`に置き、
`public/audio/se/CREDITS.md`にライセンスを追記する。
